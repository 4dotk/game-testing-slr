# Synthesis method

The synthesis plan the reviewers followed, exported verbatim from the project workbook ("Synthesis Method" sheet). Note: the "28 papers" in Stage 2, step 1 reflects the count when this plan was written; the final review includes 25 papers.

| Step | Description |
|------|-------------|
| Recommended | Two-stage, qualitative/descriptive synthesis: (1) Descriptive mapping (counts, tables, trends) + (2) Thematic synthesis (Thomas & Harden 2008) of the findings. This is the standard for software-engineering SLRs that are not quantitative (Kitchenham & Charters guidelines call it 'narrative/descriptive synthesis'). Meta-analysis is correctly excluded. |
| Reporting standard | Report the process with PRISMA 2020 (flow diagram + checklist). Add a short statement that the extraction followed Kitchenham & Charters-style guidelines. |
| Stage 1: Descriptive mapping | Use the Extraction Log dropdown columns. Report: papers per year/venue, game genres, AI techniques, goals, metrics, validation types. Output = tables + 2-3 charts. Answers 'what exists'. |
| Stage 2 – step 1: Familiarise | Each person reads the other's extraction rows (spot-check) so both know all 28 papers. |
| Stage 2 – step 2: Code | Line-by-line, tag 'Key results' and 'Limitations' text with short codes (e.g. 'persona diversity', 'sparse reward', 'human-likeness gap'). Use the Synthesis Matrix sheet. |
| Stage 2 – step 3: Descriptive themes | Group similar codes into themes (e.g. Agent design, Evaluation metrics, PCG validity, Industry deployment barriers). Aim for 4-7 themes. |
| Stage 2 – step 4: Analytical themes | Map themes to RQs; note agreements, contradictions, and gaps. A theme should be supported by >=2 papers; say how many. |
| Consistency safeguards | Same form for all papers; pilot on 4 papers; swap-check 2 papers each; one shared codebook; disagreements resolved by discussion and logged. |
| Do NOT | Don't convert qualitative findings into pooled numbers; don't exclude papers on quality now; don't add new fields after the pilot without re-checking earlier rows. |
